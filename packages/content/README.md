# 首批课程

`src/data/` 存放与 React、Tauri 和浏览器无关的纯 JSON。每个条目有稳定 ID。添加课程时沿用同类字段，将本地媒体放进 `public/media/`，运行工作区的 `pnpm test`。

- 普通话采用家庭选定的 04 合成旁白。汉字认读、字义绘本、家长和儿童选课提示、数字与加减、森林实验室、剧场旁白及古诗都读取随包 MP3。公开制作参数见 [04 旁白](sources/narration-zh.json)。
- 汉字包含字、带调拼音与示例词。英语包含英文词和中文义，美式英语单词由 Samantha 预先合成。
- 拼音使用 audio-cmn 的普通话真人录音。页面区分完整示范音与例字。录音及许可随包保留，详见 [ATTRIBUTION](public/media/pinyin/ATTRIBUTION.txt)。
- 古诗文保留指定列表中的教材分组和重复收录。每个有正文的条目含逐句文本、音频相对路径和句起点（秒）。04 版由分句音频拼成整首，句起点取拼接时的采样位置。只有索引的篇目提供来源与备注。在“遮句接背”模式下，每句可单独揭示；显示全文时每句可单听。[目录与核验记录](sources/poetry-verification.json)
- 数字和十以内算式由 `@lingyi-classroom/shared` 的确定性规则生成。题目音频文件名与其稳定 ID 对应。`add-2-3` 与 `add-3-2` 是两道题。
