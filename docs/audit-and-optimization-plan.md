## 四、签名更新与 iPhone Safari 复验

- **macOS 签名更新**。在独立应用标识的本机副本中，从 0.1.0 的启动弹窗确认安装。改动过的下载包被拒绝，原应用继续运行。恢复正确签名包，在设置页重试后应用自动重启，版本显示为 0.1.1。使用临时更新签名密钥和本机更新源；正式发布渠道、Apple 公证与 Windows 安装包另行验收。
- **拼音重播**。在「声调拼读」静音状态选择二声或例字一声，再主动点「重播声音与动画」，只播放当前所选声音。直接打开课目时，拼音和英语的入场朗读只在进入时尝试，孩子之后的首次操作可以正常播放所选内容。
- **真机音频**。在通过 USB 连接的 iPhone 14、iOS 18.5 Safari 上实点同一按钮。二声产生一个合成音，例字「八」产生一段录音，两次输出节点均测得非零信号。2026-11-21，用户通过手机扬声器试听，确认二声上扬声调和例字「八」的录音均清楚可辨。两段真机试听通过。
- **回归**。390×844 与 1100×760 Chrome 均复现了修复前的静音重播故障，修复后通过。键盘回车可重播，自动入场和作答反馈继续遵守静音。全量 107 项 Vitest、11 项 Rust 测试通过，Web 与桌面前端构建通过。本机复验数据见 `output/项目审查验收/签名更新与真机音频.json`。

- **数字帽与古诗印章**。在 `9＋1` 回合按 `1` 仍处于作答状态，再按 `0` 才选择 10。古诗按已覆盖诗句判定完成。实测《江南》从第六句开始，无论有声还是静音，播到末尾都只覆盖第六、七句；再逐句揭开前五句才获得整首印章。整首从头播放和跨教材年级印章互通也已复验。
- **听辨提示**。拼音和英语首次作答时使用科目标题，隐藏答案、口诀、翻译以及舞台上的目标插图和颜色提示。听读按钮仍可用。主动点「给我提示」或累计两次答错后才出现提示，提示本身不盖章。答对后恢复完整讲解。
- **保存与重试**。每个剧场回合分别报告回合完成和保存状态。Web 继续读写原有印章数组。重试与重置使用同一存储锁，并在写入时核对完成时的重置版本。390×844 和 1100×760 的 Chrome 中模拟配额不足，完成「火与风」后就在回合内看到提示与重试按钮，恢复写入并重试后只获得一枚主课目印章。测试也覆盖了另一标签页把已为空的记录再次重置、重置写入失败回滚，以及排队中的旧重试。macOS Tauri 独立测试档案设为只读时也能完成「曹冲称象」，恢复写入后无需重复实验即可盖章。
